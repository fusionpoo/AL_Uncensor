AL_Uncensor

An uncensor mod for Amanatsu Location. It replaces the mosaic with real geometry for both sexes and installs as a single BepInEx plugin folder; the game's own files are not modified.

Version 0.9.1 · BepInEx 6 IL2CPP · MIT

Features

Female

Vulva, perineum and anus are stitched directly into all nine crotch body meshes as one closed surface. There is no floating patch, nothing to clip and no see-through at the edges. Works in the maker, free roam and H.

Male

A modeled penis with its own UV layout and a glans detail mask. The base colour is sampled from the character's generated skin texture at runtime, so it follows skin-tone changes. Girth is 15% less than the Aicomi original.

Pubic hair and tint

Pubic hair is masked off the labia while the mons hair stays, and a soft pink tint is painted inside the slit through the body shader's own detail layer. Both are adjustable.

Female-only mode

Turn "Uncensor males" off and the plugin serves a second bundle with the vanilla penis, leaving males exactly as the game ships them.

Install

Game
Amanatsu Location, Steam build (Unity 6000.0.65f1)
Loader
BepInEx 6 IL2CPP, be.788 or newer
Size
about 19 MB: plugin, two body bundles, two masks
  1. Install BepInEx 6 IL2CPP (tested with 6.0.0-be.788) and run the game once so it generates BepInEx\interop.
  2. Download the release zip and merge its BepInEx folder into the game folder. Everything lands in BepInEx\plugins\AL_Uncensor\: AL_Uncensor.dll, body_00.unity3d, body_00.female.unity3d, cm_dankon_00_det.rg and labia_mask.r.
  3. Start the game. BepInEx\LogOutput.log should contain AL Uncensor 0.9.1 loaded and, once a character loads, redirecting lib/chara/body/body_00.unity3d -> ….

To uninstall, delete BepInEx\plugins\AL_Uncensor. If you used a version before 0.9 that replaced lib\chara\body\body_00.unity3d, restore your backup of the vanilla file.

How it works

Hardmod bundle

Three Python tools (UnityPy, trimesh, scipy) turn a vanilla body_00.unity3d plus DilleDing's Aicomi hardmod bundle into the shipped bundles. Amanatsu's units are 10× Aicomi's and the rigs are otherwise identical, so the port is a scale about the cf_j_dan101_00 bind pose for the penis and a weld-aware cut of DilleDing's female body for the vulva.

merge_female.py cuts the vulva, perineum and anus as one region, transfers Amanatsu's own skin weights and UV1–3 by nearest-surface barycentric interpolation, deletes the body triangles under it, pulls the surrounding ring onto DilleDing's surface and zips the hole boundary to the patch rim. Any bridge triangle whose face normal points against its vertex normals is re-wound. The result is one closed mesh per body variant (o_lower_type01–05, o_onepi_type01–04); the vanilla mnpb/mnpa genital meshes are emptied. Vertex colours are object-space smoothed normals encoded as (n·0.5+0.5)·255, which the body shader's outline pre-pass expects.

inject_dankon2.py ports o_dankon with DilleDing's UV layout, scales the shaft radially (--girth 0.85) and carries the same vertex attributes. make_dankon_det.py extracts the glans mask as a raw RG file, because this game ships no ImageConversion module.

Why a single mesh

The body shader (AL/skin_body) has an inverted-hull outline pre-pass (Cull Front) and back-face culling. Any open edge or back-facing triangle in skin shows as a grey sliver or a hole, and a separate patch over a hole can never be sealed against a posed, slider-scaled body. Stitching the geometry in removes the problem instead of hiding it.

Plugin

The plugin hooks every AssetBundle.LoadFromFile / LoadFromFileAsync overload and the internal funnels; a load whose path ends in lib/chara/body/body_00.unity3d is re-issued with the plugin-folder file. It swaps the mosaic material (AL/sub/mnpb) for the character's live skin material on HumanBody.SetBodyBaseMaterial, Human.Load/Reload/ReloadSkin and UpdateVisible, clears HideMoz outside H, masks the underhair texture and paints the labia tint on the female body material. The penis gets its own material clone with a flat skin-tone texture (sampled every 30 frames), body-UV textures nulled and the glans mask applied.

Troubleshooting

The plugin loaded but the genitals are the old low-poly placeholders

The bundle redirect didn't find its file. Look for hardmod bundle not found next to the plugin in the log and check that body_00.unity3d sits next to AL_Uncensor.dll. With "Uncensor males" off it needs body_00.female.unity3d instead.

Nothing changes at all

Check BepInEx\LogOutput.log for AL Uncensor … loaded. If it's missing, BepInEx isn't running: run the game once after installing it; the interop folder must exist.

The game updated

The mod keeps serving its own bundle, so it keeps working until the game changes the body prefab itself. If a new body ships, rebuild with build_bundle.sh against the new vanilla bundle, or wait for a release.

Pink tint too strong, or the hair line is wrong

Lower "Vulva pink tint"; move "Hair cut line v" up or down in steps of 0.005.

Reporting a problem

Attach BepInEx\LogOutput.log and a screenshot. Verbose logging (on by default) records every renderer swap and the bundle paths the game loads.
